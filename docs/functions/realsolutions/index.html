Function reference · Solving

realsolutions

Returns the real solutions in an interval.

For the result of solve, use realsolutions(solutions, lower, upper). It also lists the members of a periodic family that fall in the interval.

For the result of solveeqs, use realsolutions(solutions, variable, lower, upper). It returns the real values of that one variable.

Notation

realsolutions(solutionSet, lower, upper) | realsolutions(systems, variable, lower, upper)

Write it in an expression: nerdamer('realsolutions(solve(sin(x),x),-2*pi,2*pi)'), or in the Playground.

Parameters

solutionSetOrSystems
A SolutionSet from solve, or a Vector of Dictionary assignments from solveeqs.
variable
Required for system results: a plain variable whose distinct real values form the returned SolutionSet.
lower
Inclusive finite real lower bound of the requested interval.
upper
Inclusive finite real upper bound of the requested interval.

Examples

List a periodic family between -2π and 2π.

realsolutions(solve(sin(x),x),-2*pi,2*pi)
// → {-2*pi, -pi, 0, pi, 2*pi}
Open in Playground

The zeros of cosine in one period.

realsolutions(solve(cos(x),x),0,2*pi)
// → {(1/2)*pi, (3/2)*pi}
Open in Playground

No real solutions.

realsolutions(solve(x^2+1,x),-5,5)
// → {}
Open in Playground

The x-values of a system's solutions.

realsolutions(solveeqs([x+y=3,x-y=1]),x,1,3)
// → {2}
Open in Playground

Good to know

  • The interval must be finite.
  • In JavaScript, SolutionSet.generate({ interval: [lower, upper] }) and SolutionSet.generate({ indices: [first, last] }) do the same.
