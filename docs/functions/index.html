Nerdamer Notation

Function reference

Every function you can write inside nerdamer('...'). Each page shows how to call it in Notation and from JavaScript, its parameters, and examples.

Solving equations? solve solves one equation. solveeqs solves systems: linear and nonlinear, with free variables, complex solutions, more equations than unknowns, or numerically.
Looking for if, loops or let? They are in Scripting.

Algebra

factor(expression)

Factors a polynomial or an integer.

 gcd(arg1, arg2)

Returns the greatest common divisor of two polynomials or numbers.

 groebner(arg1, [arg2])

Computes a Gröbner basis of a polynomial system.

 lcm(arg1, arg2)

Returns the least common multiple of two polynomials or numbers.

 partfrac(arg1, [arg2])

Splits a fraction of polynomials into partial fractions.

 pfactor(value)

Returns the prime factors of a positive integer, smallest first, with repeats.

 pfactord(value)

Returns the prime factors of a positive integer with their counts.

 polyfactors(arg1)

Returns the factors of a polynomial as separate entries of a vector.

 simplify(arg1)

Rewrites an expression in a simpler, equivalent form.

 sqcomp(arg1, [arg2])

Rewrites a quadratic as a square plus a constant.

Assumptions and sets

assume(arg1)

Tells Nerdamer that a variable lies in a range of real numbers.

 difference(arg1, arg2)

Returns the values of the first set that aren't in the second.

 forget(arg1)

Removes the assumptions about a variable, or all assumptions.

 intersection(arg1, arg2, ...)

Returns the set of values that are in every one of the given sets.

 intersects(arg1, arg2)

Tests whether two sets have a value in common.

 is_subset(arg1, arg2)

Deprecated Use issubset instead.

 issubset(arg1, arg2)

Documentation for issubset.

 unassign(arg1)

Removes the value assigned to a variable.

 union(arg1, arg2, ...)

Returns the set of values that are in any of the given sets.

Returns the Fresnel cosine integral, the integral of cos(πt²/2) from 0 to x.

 defint(arg1, arg2, arg3, arg4)

Computes a definite integral between two numeric bounds.

 diff(expression[, variable][, order])

Differentiates an expression with respect to a variable.

 ilaplace(arg1, arg2, arg3)

Computes the inverse Laplace transform of an expression.

 ilt(arg1, arg2, arg3)

Computes the inverse Laplace transform of an expression.

 integrate(expression[, variable])

Finds an antiderivative of an expression.

 laplace(arg1, arg2, arg3)

Computes the Laplace transform of an expression.

 limit(expression, variable, value[, direction])

Computes the limit of an expression as a variable approaches a value.

 product(arg1, arg2, arg3, arg4)

Multiplies an expression over a range of an integer index.

 S(x)

Returns the Fresnel sine integral, the integral of sin(πt²/2) from 0 to x.

 sum(arg1, arg2, arg3, arg4)

Adds up an expression over a range of an integer index.

 taylor(expression, variable, center, degree)

Computes a Taylor polynomial of an expression around a point.

Complex

Returns the argument (angle) of a complex number, from -π to π.

 conjugate(arg1)

Returns the complex conjugate: i becomes -i.

 csgn(arg1)

Returns the sign of a complex number: 1 or -1.

 imagpart(arg1)

Returns the imaginary part of a complex expression.

 magnitude(arg1)

Returns the absolute value of an expression.

 phase(arg1)

Returns the argument (angle) of a complex number, from -π to π.

 polarform(arg1)

Writes a complex expression in polar form, r·e^(iθ).

 realpart(arg1)

Returns the real part of a complex expression.

 rectform(arg1)

Writes a complex expression in rectangular form, a + b·i.

Linear algebra

augment(left, right)

Joins two matrices side by side.

 cross(arg1, arg2)

Computes the cross product of two three-dimensional vectors.

 determinant(arg1)

Computes the determinant of a square matrix.

 dot(arg1, arg2)

Computes the dot product of two vectors.

 imatrix(arg1)

Creates an identity matrix of a given size.

 invert(arg1)

Returns the inverse of a square matrix.

 nullspace(matrix[, prime])

Returns a basis of the nullspace of a matrix.

 rank(matrix)

 rref(matrix[, prime])

Returns the reduced row-echelon form of a matrix.

 trace(matrix)

Returns the trace of a square matrix: the sum of its diagonal entries.

Returns the double factorial, n·(n-2)·(n-4)·….

 exp(arg1)

 floor(arg1)

 heaviside(arg1)

 log(arg1, [arg2])

 log10(arg1)

Returns the base-10 logarithm of an expression.

 max(arg1, arg2, ...)

 min(arg1, arg2, ...)

 mod(arg1, arg2)

 numeric(value[, precision])

Evaluates a number to a given number of significant digits.

 parens(arg1)

Keeps parentheses around an expression in the output.

 powmod(base, exponent, modulus)

Computes `base^exponent mod modulus` exactly, without computing the full power.

 radians(arg1)

Converts degrees to radians, exactly.

 rect(arg1)

 round(arg1, [arg2])

Rounds a number, to an integer or to a number of decimal places.

 scientific(value[, significantDigits])

Writes a number in scientific notation.

 sign(arg1)

Returns 1, -1 or 0: the sign of a real expression.

 significant(arg1, arg2)

Rounds a number to a number of significant figures.

Returns the dimensions of a vector, matrix, set or dictionary.

 sqrt(arg1)

Returns the principal square root of an expression.

 step(arg1)

Returns the unit step: 0 for negative values and 1 for zero and positive ones.

 subst(arg1, arg2, arg3)

Replaces a variable or a subexpression with another expression.

 tri(arg1)

 trunc(arg1)

Lists the variables in an expression.

coeffs(expression[, variable])

Returns the coefficients of a polynomial, from the constant term up.

 content(arg1)

Returns the greatest common divisor of a polynomial's coefficients.

 deg(arg1, [arg2])

Returns the degree of a polynomial.

 div(arg1, arg2)

 divide(arg1, arg2)

 roots(expression[, variable[, method]])

 solve(expressionOrEquation, variable[, onInterval])

 solveeqs(arg1)

Solves a system of equations and returns the solutions.

 solveEquations(arg1)

Deprecated Use solveeqs instead.

Returns the middle value.

Returns the value that occurs most often.
