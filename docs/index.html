Documentation

How are you using Nerdamer?

There are three ways to use Nerdamer. Pick the one that matches what you're writing.

New in this release: see What’s new.

→

Nerdamer Notation

Write mathematics as text and pass it to nerdamer('...').

factor(x^4-1)
solveeqs([x+y=5, x-y=1])
diff(sin(x)^2, x)

For: algebra, calculus, solving, vectors and matrices.

 →

Nerdamer Scripting Beta

Write small programs in the same text: variables, conditions, loops and your own functions.

block(
  x: 4,
  if(x > 3, x^2, x)
)

For: calculations with several steps.

 →

JavaScript / TypeScript API

Call Nerdamer from your code, and import its functions, classes and types.

import nerdamer from 'nerdamer';
import { Matrix } from 'nerdamer/structures';

const result = nerdamer('x^2+1');

For: using Nerdamer in an app.
Not sure? Typing mathematics such as factor(x^2-1): Notation. Writing if(...) or block(...): Scripting. Writing JavaScript or TypeScript: the API. The three work together; see Ways to use Nerdamer.
Error messages in your language. Nerdamer has built-in error messages for each supported language. Choose one with the LANGUAGE setting; see Settings.
