    Class Dictionary

    A key-value container where keys are strings (variable names) and values are any ParserInputType. Supports element-wise arithmetic operations.

    Syntax: {x => 1, y => 2, z => x+3} Access: d[x] → 1, d[y] → 2 Assign: d[y]: 10
