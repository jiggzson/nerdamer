    __get__

    • __get__(indices: number[]): ParserInputType

      Returns a row at the given zero-based index as a Vector. Used by the parser for bracket indexing, e.g. matrix[0] returns the first row. This enables chained indexing: matrix[0][1] returns the element at row 0, col 1.

      Parameters

      • indices: number[]

        Zero-based indices (after INDEX_BASE adjustment). Single index [i] returns row i as a Vector. Two indices [i, j] returns the element at row i, col j.

      Returns ParserInputType
