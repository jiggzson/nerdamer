JavaScript / TypeScript API

nerdamer/parser

Programmatic parser access and settings for JavaScript and TypeScript. This is separate from Nerdamer expression syntax.

Import from nerdamer/parser. For the functions you write inside nerdamer('...'), see the function reference.

Interfaces

Operator: unknownInterface

Operator metadata accepted by the parser registry. Registration accepts custom action names and the legacy prefix/postfix aliases. Prefix, postfix, and iteration flags are optional because the parser supplies defaults.

OperatorDefinition: unknownInterface

Operator metadata accepted by the parser registry. Registration accepts custom action names and the legacy prefix/postfix aliases. Prefix, postfix, and iteration flags are optional because the parser supplies defaults.

ParserAPI: unknownInterface

Supported high-level parser interface. Tokenization, RPN conversion, and parser-stack machinery remain internal implementation details even though Nerdamer itself uses them across modules.
