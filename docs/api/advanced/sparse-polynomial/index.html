SparsePolynomial

src/core/classes/polynomial/SparsePolynomial.ts:36

Sparse polynomial with bigint coefficients and bigint exponents. The variable count is part of the polynomial rather than inferred from its support. Exponent vectors therefore have one exact entry for every variable, including zero polynomials and constants. The internal map key is an encoding detail and is never exposed or parsed by polynomial algorithms.
