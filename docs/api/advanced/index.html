JavaScript / TypeScript API

nerdamer/advanced

Advanced symbolic tools including complex values and Gröbner-basis operations.

Direct npm import. The items on this page are JavaScript / TypeScript exports from nerdamer/advanced. For functions used inside nerdamer('...'), see Nerdamer Notation.
14 exports

Functions

Computes the part of the ideal that lies in the polynomial ring generated by `keepVars`.

Groebner(polys: MultiPoly[], vars: string[], order: MonomialOrder, reduced: boolean): MultiPoly[]Function

Classes

Complex: unknownClass

Represents a numerical complex value backed by `decimal.js` components.

FunctionSolver: unknownClass

Searches a bounded interval for real roots of a univariate expression.

GroebnerBudgetExceeded: unknownClass

Thrown when a Groebner pair-count or basis-size budget is exhausted. GroebnerBudgetExceeded.stats is the live counter snapshot from the aborted computation. The error keeps that object by reference and does not freeze it.

MultiPoly: unknownClass

Sparse multivariate polynomial over integer coefficients.

APIs

GroebnerBasisOptions: unknownAPI

Controls monomial order, result normalization, pair strategy, and deterministic budgets.

GroebnerStats: unknownAPI

Deterministic work counters captured when a Groebner resource budget is exceeded.

MonomialOrder: "LEX" | "GRLEX" | "GREVLEX"API

Monomial order used for leading terms, pair processing, and reduction.

RationalSolution: Map<string, { … }>API

Maps each solved variable to a reduced rational numerator/denominator pair. Only rational coordinates discovered by triangular back-substitution are represented.
