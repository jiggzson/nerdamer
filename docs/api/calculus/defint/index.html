API/nerdamer/calculus
Function

defint

src/math/math.ts:1729
defint(f: ExpressionInput, dx: ExpressionInput, from: ExpressionInput, to: ExpressionInput): Expression

Calculates the definite integral using Adaptive Simpson. Note that this function uses native JS number due to severe computational overhead when implemented with Decimal.js.

Parameters

NameTypeDescription
fExpressionInputThe function being integrated
dxExpressionInputThe variable of integration
fromExpressionInputThe lower limit of the integral
toExpressionInputThe upper limit of the integral

Returns

Expression — The numeric value if possible else a symbolic function

Examples

defint('cos(x)-x^2+6', 'x', 1, 6); // -42.787553149673464

Symbolic mathematics for JavaScript and TypeScript.
