Vector

src/core/classes/vector/Vector.ts:40

An ordered, operable parser aggregate with heterogeneous ParserEntity elements.

Details

Vector is not restricted to numeric linear-algebra values. General arithmetic is element-wise. Addition and subtraction require another Vector of equal length; multiplication, division, and powers can broadcast scalar operands. Vector-to-Vector times remains an element-wise product rather than an alias for dot. A Matrix operand interprets this Vector as a row vector for the standard Vector * Matrix product; orientation is supplied by operand position rather than stored on the Vector. Structural methods such as append, insert, extend, reverse, and trim mutate this Vector. True linear-algebra operations (dot, cross, and norm) require Expression elements. dot requires equal lengths, while cross requires two three-element Vectors. These operations throw rather than assigning arithmetic meaning to arbitrary aggregate elements. Construction from a Collection copies its elements. Construction from an array normalizes inputs but retains existing parser entities; copy deep-copies every element. Comparisons are component-wise predicates, not a total ordering, and return false for a type or length mismatch.

cross(v: Vector): VectorMethod

Computes the cross product of two vectors of the same dimension. Zero- and one-dimensional inputs return a zero vector of that dimension. In three dimensions, this is the usual cross product. In seven dimensions, the result uses a fixed octonion multiplication table: with one-based indices, the cyclic triples are (123), (145), (176), (246), (257), (347), and (365). For example, e1 × e2 = e3 and e2 × e1 = -e3. The seven-dimensional table is a choice of convention, not a unique principal cross product. Other octonion conventions can give different coordinate results. The product is antisymmetric, perpendicular to both input vectors and satisfies |a × b|² = |a|²|b|² - (a·b)² for real vectors. Unlike the three-dimensional product, it does not generally satisfy the Jacobi identity. Source for the seven-dimensional table: "On the Structure of Octonion Regular Functions", Advances in Applied Clifford Algebras (2019), Lemma 2.5, https://doi.org/10.1007/s00006-019-0983-y.

times(x: NerdamerInput): VectorMethod

Multiplies corresponding Vector elements, broadcasts a scalar factor, or multiplies this Vector from the left of a Matrix.

Details

Vector-to-Vector multiplication is the element-wise (Hadamard) product. Use dot when a scalar inner product is intended. For a Matrix operand, this Vector is interpreted as a row vector. Nonzero-width products reuse the existing Matrix-vector product through the transpose; a compatible zero-width Matrix has the empty Vector as its result because its transpose cannot be represented.
