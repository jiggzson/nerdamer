nerdamer/structures

Matrices, vectors, sets, collections, dictionaries, and related operations.

Direct npm import. The items on this page are JavaScript / TypeScript exports from nerdamer/structures. For functions used inside nerdamer('...'), see Nerdamer Notation.
9 exports

Functions

cross(a: ParserEntity, b: ParserEntity): Expression | VectorFunction

Computes a three-dimensional cross product or preserves symbolic operands.

determinant(M: Matrix): ExpressionFunction

Computes the determinant without mutating the supplied Matrix.

dot(a: ParserEntity, b: ParserEntity): ExpressionFunction

Computes the dot product of two Vectors or preserves two symbolic operands.

imatrix(x: Expression): Expression | MatrixFunction

Creates an identity matrix of integer size.

Classes

Dictionary: unknownClass

A rectangular two-dimensional matrix of scalar Expression elements.

Symbolic mathematics for JavaScript and TypeScript.
