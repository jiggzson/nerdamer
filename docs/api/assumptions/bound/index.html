Bound: Readonly<{ … }>

One endpoint of an Assumption interval. Infinity is always represented as an open endpoint because it is not itself a member of a real interval. value remains Decimal-facing for API compatibility; finite bounds retain exact rational or real-power expressions internally. Its Decimal value may be rounded; use the interval methods for proofs.
