nerdamer.max

src/index.ts:780
nerdamer.max(...args: ExpressionInput[]): Expression

Returns the maximum value from a set of expressions. If all arguments can be compared numerically (or have assumed numeric values), returns the largest. Otherwise returns a symbolic

`max(...)`

node.

Parameters

NameTypeDescription
argsExpressionInput[]Two or more expressions to compare.

Returns

Expression — The maximum value, or a symbolic `max(...)` node.

Examples

max(1, 3, 2).text()     // "3"
max(-5, 0).text()       // "0"
max('x', 'y').text()    // "max(x, y)"

Symbolic mathematics for JavaScript and TypeScript.
