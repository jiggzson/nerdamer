nerdamer.set

nerdamer.set(setting: string | OptionsObject, value?: string | number | bigint | boolean): typeof nerdamer

Changes one or more shared parser settings. The legacy PRECISION setting is routed through Parser.setPrecision so Decimal-backed calculations and the finite-precision pi and e constants remain synchronized.

Parameters

NameTypeDescription
settingstring | OptionsObjectSetting name or settings object accepted by Parser.set.
valuestring | number | bigint | booleanValue used when setting is a single name.
