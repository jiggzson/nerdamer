Programmatic API

JavaScript / TypeScript API

Everything you can import from Nerdamer in JavaScript or TypeScript: the nerdamer object, and the functions, classes and types in each import path. The functions you write inside nerdamer('...') are in the function reference, which also shows each one's JavaScript forms.

One operation, three forms.
nerdamer('factor(x^2-1)')   // Notation
nerdamer.factor('x^2-1')    // method on nerdamer
factor('x^2-1')             // imported from nerdamer/algebra

See Ways to use Nerdamer.

The nerdamer object

nerdamer is a function that reads Notation, with methods such as nerdamer.factor(...), nerdamer.setFunction(...) and nerdamer.set(...).

Import paths

Import functions, classes and types from these paths.

nerdamer/core37 exports

Expressions, equations, numeric values, conversion helpers, errors, and other core building blocks.

nerdamer/algebra27 exports

Polynomial tools, factorization, simplification, rational expressions, and related algebra operations.

nerdamer/calculus12 exports

Differentiation, integration, limits, sums, products, and Laplace transforms.

nerdamer/special12 exports

Gamma, error, exponential, logarithmic, sine, and cosine special functions.

nerdamer/statistics11 exports

Mean, median, mode, variance, standard deviation, and z-scores.

nerdamer/solve13 exports

Equation solvers, system solvers, solution containers, and solver options.

nerdamer/structures18 exports

Matrices, vectors, sets, collections, dictionaries, and related operations.

nerdamer/assumptions10 exports

Assumptions attached to symbols and helpers for reading or clearing them.

nerdamer/parser17 exports

Programmatic parser access and settings for JavaScript and TypeScript. This is separate from Nerdamer expression syntax.

nerdamer/advanced18 exports

Advanced symbolic tools including complex values and Gröbner-basis operations.

Symbolic mathematics for JavaScript and TypeScript.
